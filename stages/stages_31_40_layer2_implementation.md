## 📦 核心API

### 1. TaskNode（子任务节点）
```python
node = TaskNode(
    node_id="step_1",
    task=my_task,
    dependencies=["init"],
    node_type=NodeType.SERIAL
)

node.mark_in_progress()
node.mark_completed(output_data)
```

### 2. TopologicalDecomposer（DAG管理器）
```python
decomposer = TopologicalDecomposer()

# 添加任务
decomposer.add_task(task_a)
decomposer.add_task(task_b, dependencies=["a"])

# 验证
is_valid, issues = decomposer.validate_dag()

# 执行顺序
order = decomposer.get_execution_order()  # [['a'], ['b']]

# 自动标记类型
decomposer.auto_mark_node_types()
```

### 3. SubtaskSplitter（子任务拆分器）
```python
splitter = SubtaskSplitter()

# 按步骤拆分
subtasks = splitter.split_task_by_steps(main_task, [
    "Load", "Process", "Save"
])

# 创建依赖配置
configs = splitter.create_dependency_configs(subtasks)
```
